# Claude and AI-Agent Frontend Workflows

Fast-changing knowledge about using coding agents effectively for UI implementation.

## Scope
Research design context files, screenshots/references, visual specifications, agent skills, component constraints, iterative browser inspection, screenshot comparison, visual regression, accessibility checks, frontend testing, design-system context, task decomposition, and long-running improvement loops.

## Separation rule
Do not put durable UI/UX principles here merely because Claude can use them. This file is for agent-specific execution techniques. Date or scope model/tool-specific behavior.

## Desired outcome
Convert findings into instructions another coding agent can immediately apply: what context to load, what artifacts to inspect, what to implement first, when to render and inspect, how to diagnose generic output, and how to iterate safely.
