# Interaction and Motion

Knowledge about state transitions, microinteractions, direct manipulation, gestures, animation, and spatial continuity.

## Durable rule
Motion should primarily improve understanding, feedback, continuity, perceived responsiveness, or useful delight.

Evaluate significant motion for user benefit, interruption cost, input modality, reduced-motion behavior, runtime performance, mobile constraints, and whether the same goal can be achieved more simply.

## Research directions
View transitions; shared-element transitions; gesture-driven interfaces; scroll-linked motion; drag-and-drop; tactile microinteractions; loading/perceived performance; spatial navigation; animation orchestration.
