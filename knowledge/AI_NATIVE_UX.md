# AI-Native UX

Patterns for products incorporating models, copilots, generative systems, or autonomous agents.

## Core questions
- What should AI do automatically?
- What remains explicitly user-controlled?
- How is uncertainty communicated?
- How can users inspect or verify outputs?
- What can be undone?
- When is approval required?
- How is progress shown?
- How are sources/provenance represented?
- How does the system recover when the model is wrong?
- Is conversation actually the best interaction model?

## Research domains
Agent activity views; approval checkpoints; editable plans; generated previews; contextual AI actions; AI-enhanced search; mixed-initiative interaction; adaptive interfaces; provenance; uncertainty; persistent agent memory; undo/recovery; delegation controls; background work; human-agent handoff.

Do not treat AI-native UX as synonymous with chat UI.
