# UX Patterns

Reusable interaction patterns and their tradeoffs.

## Pattern structure
When useful, document: problem solved, when to use, when not to use, interaction model, desktop/mobile behavior, accessibility, failure modes, implementation notes, evidence, and maturity.

## Initial research domains
Navigation; search; filtering; forms; onboarding; settings; tables/data grids; dashboards; feeds; catalogs; authentication; empty/loading/error states; notifications; dialogs/drawers; tabs; command palettes; contextual actions; comparison; bulk operations; undo/recovery.

Prefer task-oriented guidance over component catalogs.
