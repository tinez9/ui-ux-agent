# Core Design Intelligence

High-density principles for AI agents designing digital products.

## Product before surface
Start from user tasks, product goals, information structure, audience, brand, and constraints before choosing an aesthetic.

## Hierarchy before decoration
Make importance visible through structure, typography, spacing, placement, contrast, and progressive disclosure before decorative effects.

## Familiarity and differentiation are complementary
Use familiar interaction patterns for routine tasks. Spend novelty where it creates product value, brand identity, stronger comprehension, or memorable interaction.

## Coherence beats component accumulation
A product should feel governed by intentional rules for typography, spacing, color, shape, depth, motion, component behavior, and content tone.

## Responsive design is recomposition
Do not treat mobile as scaled-down desktop. Reconsider hierarchy, density, navigation, ordering, input method, target size, and persistent controls.

## Motion needs a job
Use motion for state change, spatial relationship, continuity, hierarchy, feedback, progress, or useful delight. Support reduced motion.

## Accessibility is a design constraint
Accessibility should influence color, typography, focus, semantics, motion, input methods, content structure, and interaction from the start.

## Performance affects experience
Heavy visuals, animation, 3D, video, large assets, and client-side behavior carry UX cost. Evaluate whether each effect earns that cost.

## AI is not automatically a chat box
AI may appear as search, suggestions, transformations, contextual actions, generated previews, adaptive workflows, background agents, or conversation. Choose the interaction model that fits the task.

## Preserve user control
For consequential AI actions, make state, scope, progress, approval, undo, recovery, and provenance understandable.

## Avoid generic AI composition
Do not reflexively default to the same hero + gradient + floating cards + rounded panels + generic feature grid. Derive visual direction from the product.

## Treat trends as inputs, not answers
A trend can provide vocabulary or inspiration. It does not replace product reasoning or UX evidence.

## Implementation matters
Recommendations are strongest when another agent can understand what to build, why, when, edge cases, responsive behavior, accessibility, performance implications, and implementation path.
